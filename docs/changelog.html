Changelog

All notable changes to FRITZ!Power Monitor are documented here.

Changes are tracked in date-based entries. See the GitHub Releases for published versions.

[17.11.2026]

Added

  • Added a first-run setup assistant for FRITZ!Box credentials, device discovery and optional weather configuration (#498).
  • Added an animated solar/grid energy-flow view showing household consumption, solar generation, self-consumption and grid import/export (#461).
  • Added one-click application updates in Diagnostics for Flatpak, Debian packages, AppImages and source checkouts, with checksum verification where applicable (#464).
  • Added a timestamped Diagnostics activity timeline covering refreshes, device discovery, weather requests, release checks and update installation, including recent FRITZ!Box HTTP response details (#479).

Changed

  • Redesigned the settings overview into clearly grouped Interface, Display & updates, Data sources, Layout and Support sections (#497).
  • Displayed forecast high and low temperatures on separate, right-aligned lines for easier scanning (#495, #496).
  • Restored paired weather/temperature and consumption/solar readings in two-line panel mode while preserving configured item order (#499).
  • Stacked the unit below an unpaired panel value in two-line mode, keeping paired values and single-line mode compact (#501).
  • Made history graphs collapsible, individually or in related pairs, and persisted disclosure states across applet restarts; this includes current-power history, total input/output and temperature graphs, bandwidth graphs, and per-device power/temperature pairs (#480, #484, #486, #488, #489, #490, #493).
  • Reduced popup CPU usage by preprocessing and caching weather images and reducing redundant diagnostics, slideshow and energy-flow redraws (#481, #482, #487).
  • Changed the weather background on every manual reload while preserving the selected slideshow position when refreshed images arrive (#477).
  • Added metric axes and MIN/MAX/CURRENT values to compact and expanded graphs, simplified power and temperature unit labels, and aligned expanded graph layout with compact graphs (#462, #467, #469, #470).
  • Restricted Wikimedia weather backgrounds to natural scenery and astronomy, removed the chessboard overlay and made photo backgrounds translucent (#448, #449, #483).

Fixed

  • Fixed repository selection in the workflow CLI and release lockfile resolution; corrected the AppImage updater's asynchronous permission update (#466, #471, #476).
  • Fixed TLS diagnostics severity when certificate validation is explicitly disabled, and clarified installed/latest version status indicators (#472, #475).
  • Fixed broken README and security-policy links on the website and user guide (#474).

Documentation and Website

  • Added persistent light/dark/system theme and German/English language controls to the landing page and user guide (#444, #454).
  • Added CLI commands and Make targets for publishing Pages, publishing releases, building packages, listing workflows and watching workflow runs (#468).
